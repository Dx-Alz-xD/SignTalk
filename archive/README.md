# archive

Work that is finished with, kept because it is easier to look at than to dig
out of git history. Nothing here is built, run or imported by the rest of the
project.

## ui-2-prototype

The first trainer interface, built before `Frontend/UX` existed. It covered a
landing page, an "add new vocabulary" form and a camera workspace, and it is
where the design language that `Frontend/UX` still uses was worked out: the
warm neutral palette, the mono labels, the card treatments.

Superseded by the Trainer inside `Frontend/UX`, which does the same job against
the real API. Its `node_modules` and build output were removed; `pnpm install`
inside the folder would bring it back to life if anyone wanted to run it.

Safe to delete outright. It is in the git history either way.
